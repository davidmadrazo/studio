# **App Name**: BizFind

## Core Features:

- Input Form: Form with fields for business type, location, and number of results.
- API Submission: Send form data as a POST request to https://webhookn8n.profimaxia.com/webhook/ae226503-4cbf-418e-98fd-d864e2ee388c
- Submission Confirmation: Display a confirmation message upon successful submission.

## Style Guidelines:

- Primary color: Slate blue (#577590) for trust and reliability.
- Background color: Light gray (#E5E6E8) to ensure readability and neutrality.
- Accent color: Yellow-orange (#F9C74F) to highlight the submit button and interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective feel.
- Simple, centered layout for easy user interaction.
